# BKK & Pattaya Trip · Aug 21-24, 2026

A mobile-first trip companion PWA for Stevey & daughter's Bangkok + Pattaya trip.

## Features
- 📅 Day-by-day itinerary with timeline
- 🏨 Hotel quick-dial + map links
- ✅ Interactive booking & packing checklists (saves locally)
- 🚨 Emergency one-tap calling
- 💦 Live countdown to trip
- 📱 PWA — install to home screen, works offline
- 🖨️ Print-friendly layout

## Stack
- Single-file HTML + Tailwind via CDN
- Vanilla JS (no build step)
- PWA manifest + service worker for offline

## View locally
```
python3 -m http.server 8080
# open http://localhost:8080
```

## Deploy
Pushed to GitHub Pages. Live URL set in repo description / About section.
